## 접근법

- 재귀 DFS를 사용하면서 현재 노드의 깊이(`depth`)를 함께 전달한다.
- 오른쪽 자식을 왼쪽 자식보다 먼저 방문한다.
- 각 깊이를 처음 방문했을 때의 노드가 오른쪽에서 보이는 노드이므로 `answer`에 추가한다.
- 이미 해당 깊이의 노드를 방문했다면 추가하지 않는다.
- 오른쪽 subtree가 없는 경우에는 왼쪽 subtree의 노드가 해당 깊이의 보이는 노드가 된다.

## 시간·공간 복잡도

- 시간 복잡도: O(n)
- 공간 복잡도: O(n), 결과 리스트와 재귀 호출 스택 포함
