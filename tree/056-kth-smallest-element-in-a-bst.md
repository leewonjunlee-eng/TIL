## 접근법

- BST에서 왼쪽 → 현재 노드 → 오른쪽 순서로 방문하는 중위 순회를 사용한다.
- BST의 중위 순회 결과는 오름차순이므로, 노드를 방문할 때마다 `count`를 1 증가시킨다.
- `count`가 `k`와 같아지는 순간 현재 노드의 값을 정답으로 저장한다.
- 중첩 함수에서 `count`와 `answer`를 변경하므로 `nonlocal`을 사용한다.
- 빈 노드에 도달하면 재귀를 종료한다.

## 막힌 지점 또는 틀린 이유

- 재귀 함수에 `count`를 직접 전달하는 방식보다, 바깥 함수의 상태를 `nonlocal`로 유지하는 방식이 이 문제에 더 간단하다는 것을 확인했다.
- `return`은 현재 재귀 호출만 종료하므로 k번째 값을 찾은 뒤에도 일부 탐색이 이어질 수 있지만, 이후 `count`가 `k`보다 커져 정답이 변경되지는 않는다.

## 시간·공간 복잡도

- 시간 복잡도: O(n)
- 공간 복잡도: O(h), 재귀 호출 스택

## 다음에 기억할 한 줄

- BST에서 중위 순회를 하면 값이 오름차순으로 방문되므로, k번째 방문 노드가 k번째로 작은 값이다.
