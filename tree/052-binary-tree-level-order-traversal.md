## 접근법

- 재귀 DFS를 사용하면서 현재 노드의 깊이(`depth`)를 함께 전달한다.
- 현재 노드의 값은 `answer[depth]`에 추가한다.
- 해당 깊이의 리스트가 아직 없으면 새 리스트를 만든다.
- 왼쪽 자식과 오른쪽 자식은 현재 깊이에 1을 더해 재귀 호출한다.
- 전위 순회에서 왼쪽 subtree를 먼저 방문하므로 같은 레벨의 값이 왼쪽부터 저장된다.

## 시간·공간 복잡도

- 시간 복잡도: O(n)
- 공간 복잡도: O(n), 결과 리스트와 재귀 호출 스택 포함
