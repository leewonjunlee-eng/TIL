# Valid Palindrome

## 접근법

문자열 전체를 새로 필터링하거나 리스트로 복사하지 않고, 양쪽 포인터로 원본 문자열을 직접 비교한다.

왼쪽 포인터와 오른쪽 포인터가 가리키는 문자가 알파벳·숫자가 아니면 건너뛴다. 두 문자를 소문자로 바꿔 비교하고, 다르면 즉시 False를 반환한다. 같으면 두 포인터를 안쪽으로 이동한다.

## 시간·공간 복잡도

- 시간: O(n)
- 공간: O(1)

문자열을 최대 한 번 순회하므로 시간은 O(n)이다. 포인터 변수만 사용하고 별도의 문자열이나 리스트를 만들지 않으므로 추가 공간은 O(1)이다.

## 막힌 지점 또는 틀린 이유

처음에는 filtered, forward, backward 리스트를 만들어 공간을 O(n) 사용했다. 양쪽 포인터를 사용하면 같은 시간복잡도를 유지하면서 공간을 줄일 수 있다.

## 다음에 기억할 한 줄

양끝에서 비교할 수 있는 문제는 두 포인터로 원본을 직접 순회하면 공간을 O(1)로 줄일 수 있다.
