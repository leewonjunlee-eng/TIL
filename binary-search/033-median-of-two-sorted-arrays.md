## 접근법

- 두 배열을 합치지 않고, 전체를 왼쪽과 오른쪽 파티션으로 나눈다.
- 더 짧은 배열에서 왼쪽 파티션 크기 `i`를 이진 탐색한다.
- 다른 배열의 파티션 크기 `j`는 왼쪽 전체 원소 수가 `(m + n + 1) // 2`가 되도록 정한다.
- `left1 <= right2`와 `left2 <= right1`이면 파티션이 올바르다.
- 홀수 개면 왼쪽 최댓값, 짝수 개면 왼쪽 최댓값과 오른쪽 최솟값의 평균을 반환한다.

## 시간·공간 복잡도

- 시간 복잡도: O(log(min(m, n)))
- 공간 복잡도: O(1)

- 두 정렬 배열의 중앙값은 작은 배열의 파티션 위치를 이진 탐색해 찾는다.
