## 접근법

- `dict`에는 `key: Node`를 저장해 key로 노드를 O(1)에 찾는다.
- 이중 연결 리스트는 사용 순서를 관리한다.
- `left`와 `right`는 실제 값을 저장하지 않는 dummy 노드다.
- `right` 바로 앞을 가장 최근 사용된 노드로 둔다.
- `left` 바로 뒤를 가장 오래 사용되지 않은 노드로 두고, 용량을 초과하면 삭제한다.
- `get`으로 조회한 노드와 기존 key를 갱신한 노드는 기존 위치에서 제거한 뒤 가장 최근 위치로 옮긴다.

## 시간·공간 복잡도

- `get`: O(1)
- `put`: O(1)
- 공간 복잡도: O(capacity)

## 막힌 지점 또는 틀린 이유

- `capacity`는 최대 용량이므로 수정하지 않고 `len(self.store)`와 비교한다.
- `get`도 최근 사용으로 취급되므로 노드를 `right` 앞에 다시 붙여야 한다.
- 기존 key를 `put`할 때는 새 값만 저장하는 것이 아니라 기존 노드를 먼저 연결 리스트에서 제거해야 중복 노드가 남지 않는다.
- `.next`와 `.prev`는 함수가 아니라 Node 객체에 저장하는 속성이다.
